# 第一章：认识 Hermes Agent

## 1.1 什么是 Hermes Agent？

Hermes Agent 是由 [Nous Research](https://nousresearch.com) 打造的自改进 AI Agent。它不是一个绑定了 IDE 的代码助手，也不是围绕单一 API 的聊天机器人包装器，而是一个**能够自我进化的自主 Agent**——使用时间越长，能力越强。

### 核心定位

| 特性 | 描述 |
|------|------|
| **类型** | 自主 Agent（Autonomous Agent） |
| **开发者** | Nous Research |
| **核心能力** | 内置学习循环，持续自我改进 |
| **部署方式** | $5 VPS、GPU 集群、无服务器架构（Daytona、Modal） |
| **交互方式** | CLI、Telegram、云端 VM |

### 与传统工具的区别

```
传统 Copilot：绑死在 IDE，每次对话独立，无记忆
Hermes Agent：跨会话记忆，自动学习，持续进化
```

## 1.2 核心特性

### 🧠 持久记忆系统

Hermes Agent 拥有**跨会话的持久化记忆**。它能够：
- 记住用户的偏好、习惯、工作方式
- 在多次会话中积累上下文
- 主动回忆之前讨论过的内容

### 📚 Skills 系统（程序化记忆）

Skills 是 Agent 自我创建的可复用技能模块：

- **自动创建**：Agent 从经验中生成 Skills
- **持续改进**：在每次使用中优化 Skills
- **跨会话复用**：新会话可以调用历史 Skills
- **显式知识**：用户可以查看、编辑、删除 Skills

### 🔌 MCP 集成

Model Context Protocol（MCP）集成允许 Hermes Agent：
- 连接外部 MCP 服务器
- 过滤不需要的工具
- 安全地扩展功能
- 访问更多数据源和 API

### 🎙️ 语音模式

支持多种平台的实时语音交互：
- CLI 终端
- Telegram
- Discord
- Discord 语音频道（VC）

## 1.3 工作原理

### 架构概览

```
┌─────────────────────────────────────────────────────────────┐
│                     Hermes Agent                             │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────┐  ┌──────────┐  ┌────────┐  ┌─────────────┐     │
│  │  CLI    │  │  TUI     │  │ Gateway │  │  Voice Mode │     │
│  └────┬────┘  └────┬─────┘  └────┬───┘  └──────┬──────┘     │
│       │            │             │              │            │
│  ┌────▼────────────▼─────────────▼──────────────▼────┐     │
│  │                  Core Agent Engine                  │     │
│  │  ┌─────────┐  ┌──────────┐  ┌────────────────┐      │     │
│  │  │ Memory  │  │  Skills   │  │ Tool Gateway   │      │     │
│  │  │ System  │  │  System   │  │ (47 Tools)     │      │     │
│  │  └─────────┘  └──────────┘  └────────────────┘      │     │
│  └────────────────────────┬─────────────────────────────┘     │
│                           │                                   │
│  ┌────────────────────────▼─────────────────────────────┐    │
│  │              AI Provider (可配置)                      │    │
│  │  Claude / GPT-4 / OpenRouter / Ollama / 本地模型     │    │
│  └───────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

### 交互流程

```
用户消息 → 记忆检索 → Agent 推理 → 工具调用（如需要）→ 响应生成 → 记忆更新
```

### 学习循环

```
1. 执行任务 → 观察结果
2. 如效果不佳 → 创建/更新 Skill
3. 保存经验 → 持久化到磁盘
4. 下次遇到类似任务 → 调用已有 Skill
```
